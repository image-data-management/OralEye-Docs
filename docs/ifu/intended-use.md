# Intended Use

## Device Description

The OralEye Oral Imaging System is a portable, non-invasive imaging device designed for capturing high-resolution intraoral images using visible and fluorescence imaging modalities.

## Intended Purpose

The OralEye system is intended for:

- Capturing intraoral photographs for diagnostic purposes
- Documenting oral conditions and treatment progress
- Patient education and communication
- Integration with digital patient records

## Intended Patient Population

- **Age Range:** All ages
- **Conditions:** General oral health screening and documentation
- **Contraindications:** None known

## Clinical Benefits

- Enhanced visualization of oral structures
- Improved patient communication
- Comprehensive documentation
- Support for treatment planning

## Indications for Use

The device is indicated for use in dental practice settings for capturing and storing intraoral images to assist in:

1. Clinical examination
2. Diagnosis and treatment planning
3. Patient record documentation
4. Patient education

## Contraindications

There are no known contraindications for use of this device when used as directed.

## Warnings

:::warning
- This device is prescription-use only and should be operated by trained dental professionals
- Not intended for use as the sole basis for diagnosis
- Images should be interpreted by qualified dental professionals
:::

## Device Classification

- **Type:** Intraoral camera system
- **Modalities:** 
  - Visible light reflectance imaging
  - Fluorescence imaging
- **Portability:** Handheld, battery-operated
